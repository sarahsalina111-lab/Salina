# نماذج SALINA WHITE FRIDAY: طريقة التعديل

كل تصميم ملف HTML لوحده، فيه نص حقيقي ورسومات SVG. مفيش جوه الملفات أي صورة جاهزة غير اللوجو.
الصور النهائية PNG بتطلع من الملفات دي، فأي تعديل بيتعمل هنا، وبعدين تطلّعي الصورة تاني.

| التصميم | ملف المصدر | الصورة النهائية |
|---|---|---|
| ١ Typography | `sample-1-typography.html` | `../../08-EXPORTS/samples/salina-wf-sample-1-typography.png` |
| ٢ الدولاب | `sample-2-wardrobe.html` | `../../08-EXPORTS/samples/salina-wf-sample-2-wardrobe.png` |
| ٣ العرض (قالب) | `sample-3-offer.html` | `../../08-EXPORTS/samples/salina-wf-sample-3-offer.png` |

ملفات مشتركة:
- `base.css`: ألوان الحملة وإعدادات الخطوط المشتركة.
- `../../01-BRAND-ASSETS/fonts/`: ملفات خطوط Tajawal وCairo، فالتصميم مش محتاج نت.
- `../../01-BRAND-ASSETS/salina-logo-transparent.png`: اللوجو.

## تعديل النصوص
- افتحي ملف التصميم في أي محرر نصوص، ودوّري على الجملة نفسها، مثلًا `الخصم بيخلص.`، وغيّريها.
- كل جملة مكتوب جنبها مكانها وحجمها، مثلًا `top:300px;font-size:116px`.
- **في قالب العرض:** مش محتاجة تلمسي التصميم خالص. في آخر الملف هتلاقي جزء اسمه `COURSE`، اكتبي فيه البيانات:
  ```js
  const COURSE = { type: "ورشة", title: "...", trainer: "...", duration: "...", mode: "...",
                   start: "...", price_old: "...", discount: "...", price_new: "..." };
  ```
  أي خانة فاضية بيفضل مكانها `[...]`. ولو اسم الورشة أو السعر طويل، الخط بيصغر لوحده عشان مايطلعش برا البطاقة.

## تعديل الألوان
- كل ألوان الحملة متعرّفة مرة واحدة في `base.css`:
  `--pu` بنفسجي، `--gd` ذهبي، `--vi` بنفسجي فاتح، `--cr` كريمي، `--ch` فحمي، `--tint` بنفسجي باهت.
- لو غيّرتي لون من هنا، بيتغير في الكلام والأشكال والرسومات في الثلاث تصميمات.
- فيه ثلاث درجات تظليل بس مكتوبة جوه الرسومات نفسها: `#8E62A8` قاعدة اللابتوب، و`#463A52` كعب الكتاب، و`#6A4483` النقط اللي ورا الكلام في التصميم ١.

## تعديل العناصر
- كل رسمة متجمعة جوه `<g transform="translate(x y) rotate(..) scale(..)">`:
  - غيّري `translate` عشان تحرّكيها.
  - غيّري `scale` عشان تكبّريها أو تصغّريها.
  - احذفي الجروب كله عشان تشيليها.
- فوق كل جزء ملاحظة بتقول هو إيه، مثلًا `<!-- top shelf: books -->` و`<!-- bottom: hanging bulb -->`.
- اللوجو عنصر `<img>`، ومكانه وحجمه مكتوبين في `style` بتاعه.

## التصدير والمراجعة
```bash
node SALINA-WHITE-FRIDAY/07-SOURCE-FILES/qa-post.js SALINA-WHITE-FRIDAY/03-SOCIAL-POSTS/samples/sample-3-offer.html SALINA-WHITE-FRIDAY/08-EXPORTS/samples/salina-wf-sample-3-offer.png
```
الأمر ده بيطلّع صورة بمقاس 1080×1350 بالظبط، وقبلها بيراجع الحاجات دي:
- أي كلام طالع برا الكادر بيتعلّم `OUT`.
- أي محتوى متقطّع جوه البطاقة بيظهر تحت `CLIPPED`.
- أي كلام تباينه ضعيف بيتعلّم `LOW`.
- اسم كل خط اتحمّل.
- أي ملف ناقص ماتحمّلش.
